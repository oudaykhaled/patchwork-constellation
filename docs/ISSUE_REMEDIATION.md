**Candidate** means the issue lane supplies the scoped implementation and meaningful acceptance evidence, with the named combined checks still required before closure. **Partial** means an identified original acceptance or verification requirement remains beyond routine integration. Neither means that an issue has been closed, a release approved, or all combined tests have passed. This audit read the reported results; it did not rerun or add them together as one test run.
