# #17 · Accessible core review

Implemented on 2026-11-03 against the Constellation MVP. This report is evidence for the implemented subset, not a WCAG conformance declaration or a completed human study.

| Acceptance criterion | Implementation and evidence | Remaining gate |
| --- | --- | --- |
| Synchronized virtualized file/island alternative | `FileList` renders at most 36 semantic list items per result window. Every file remains reachable through named Previous/Next controls, path/island/status filters, and Home/End/Page/arrow navigation. List positions expose full result size. Rows contain physical path, current island, observed change kinds, selected source labels/count, overlap text/symbol, directed import counts and an Inspect action. A focused island can be opened from its filter. The 10k fixture test traverses all 10k IDs, rather than truncating at 300. | Recheck with the integrated DATA-05 hierarchy and UX-03 inspector. |
| Keyboard paths and focus return | Native modal controls retain browser focus trapping and Escape. A file selected in the list opens its inspector; closing it returns to the persistent Files launcher instead of a removed virtual row. Browser tests exercise End/Home across six windows, overlap filtering and inspector/launcher return. Existing keyboard camera/source/search journeys remain. | Human assistive-technology review on supported browser/AT combinations. |
| Settled announcements | `ReviewAnnouncements` announces settled source/file/overlap/coverage and selected-path data after work completes. It debounces data changes and excludes camera and hover inputs. File result windows announce the full matching count. | Test actual speech with NVDA/Firefox and VoiceOver/Safari; the graph zoom output must remain `aria-live="off"` when integrated with #15. |
| Status beyond color | List rows use visible Changed/Context/Overlap words, observed kind text and distinct ●/○/◎ symbols. Full selected-source labels and overlap counts are spoken as text. Focus outline is explicit. System forced-color styles give island labels/panels a system background and visible borders. Mobile icon-only AI and edit-selection controls now have explicit names. | Manual high-contrast/color-discrimination assessment of the canvas itself; the file alternative is available. |
| WCAG 2.2 AA evaluation | Added pinned `@axe-core/playwright` 4.14.0. Automated tagged checks cover default graph, source picker, explorer, inspector and narrow forced-color state. A real source-picker metadata contrast failure (4.36:1 in selected rows) was fixed; automated scans report zero violations for these states. | Automated tests cannot establish conformance: full text magnification, hover/focus content, nontext canvas contrast and human review remain. |
| Reduced motion and narrow flow | Existing reduced-motion style is retained. A 390×844 forced-color/reduced-motion journey verifies all list facts, island/status filters, no horizontal modal overflow, dismissal and launcher focus. Desktop 80%-area tests stay in the browser suite. | Real touch, 200% text resizing and physical-device matrix. |
| Keyboard/screen-reader review | Automated keyboard and accessible-name/role assertions run on the production frontend, with axe artifacts attached per state. No speech engine or human screen-reader result is claimed. | Representative human screen-reader journey is outstanding. |
| Task-based review | The automated review selects the existing three-PR state, finds the 14-file overlap subset and opens a file's directed import evidence. The synthetic demo deliberately does not open a fake GitHub diff. | A small human study must use an authorized real repository to explain a connection and open its genuine diff; no success metrics have been invented. |

## Reproduce

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm exec vitest run apps/web/src/components/file-list-model.test.ts
pnpm build
pnpm exec playwright install chromium firefox webkit
pnpm exec playwright test accessibility.spec.ts constellation.spec.ts
```

An installed local Chrome can be used with `PLAYWRIGHT_CHROME=1`. The agent's production runs used an isolated loopback port (4417), one browser worker, no model credentials, and no external source data. Core browser evidence remains deterministic. The checked-in tests run through the regular project configuration in CI.

## Observed checks

- TypeScript and production build pass.
- Unit suite: 92 pass; one optional PostgreSQL integration test explicitly skips without its database.
- New model tests: exact 212/68/14 counts and directed 235-edge totals; complete 10k-file window coverage.

A real WebKit pointer/focus-return failure found during this run was fixed and both engines reran the affected journey successfully.
