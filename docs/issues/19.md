| Source-selection invariance | PR/commit source overlays and change status do not participate in the revision identity. Contract regression toggles PR/commit/empty overlays and checks exact revision equality. Existing source-only inventory reconciliation remains coordinated with AI-04: actual new inventory is currently a reconciliation, not a user undo step. Verify the final source-only ghost-file path after integration before closing this issue. |
| Disabled/unavailable fallback | Missing credentials and disabled mode return a versioned retained baseline with zero outbound calls, zero analyzed files and no claimed model decision. Existing manual overrides retain their manual source label instead of being mislabeled as new rule grouping. Existing provider failure tests retain usable membership. |

The service validates before registering proposals, committing revisions, returning existing revisions and restoring versioned history. Invalid legacy grouping files fail closed with a readable storage error; AI-04 owns explicit durable migration and concurrency behavior. Optional confidence remains absent when unobserved; it is not synthesized as certainty.
