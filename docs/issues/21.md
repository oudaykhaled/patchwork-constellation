## Commands and results

```sh
pnpm install --offline --frozen-lockfile
pnpm exec vitest run packages/ai/src
pnpm check
pnpm exec tsx packages/ai/src/provider-smoke.ts
```

The three AI suites passed **47 tests**. Full `pnpm check` passed typecheck, **117 tests** and production build; one existing PostgreSQL integration test skipped because no test database was configured. The credential-free smoke returned `blocked` / `INTEGRATION_GATE_REQUIRED` with exit code 1, as expected, and sent no requests. The production browser bundle contained no TypeSafe/OpenAI endpoints, provider environment-variable names or smoke-command code. The integrated source formatter/static lint passed on all seven changed files.

After the account owner configures server-side `TYPESAFE_API_KEY`, a versioned `JEV_MODEL`, `OPENAI_API_KEY` and a pinned `OPENAI_MODEL`, the explicit opt-in command is:

```sh
pnpm exec tsx packages/ai/src/provider-smoke.ts --live --reviewed-data-terms --reviewed-account-limits
```

Running that command may incur provider charges. The flags attest that the operator has authorized the synthetic calls and reviewed both providers' applicable account terms and quotas. Do not place keys on the command line or save them in an issue/report. Review the emitted redacted result before attaching it. A passing transport smoke does not establish grouping accuracy, calibrated thresholds, approved data retention or rollout eligibility; AI-06 remains the quality gate.

## Primary references checked

- [TypeSafe JavaScript SDK](https://docs.typesafe.ai/sdk/javascript) and [API reference](https://api.typesafe.ai/redoc): the adapter calls the official HTTP API directly without adding an SDK dependency.
- [Choice](https://docs.typesafe.ai/primitives/choice), [Score](https://docs.typesafe.ai/primitives/score), [Noul](https://docs.typesafe.ai/primitives/noul): primitive-specific request and response shapes; confidence represents model uncertainty rather than measured accuracy.
- [Models](https://docs.typesafe.ai/models): aliases versus versioned IDs, actual response model, discovery, organization quotas and data-handling links. No account-specific quota, retention or enterprise ZDR claim is made.
