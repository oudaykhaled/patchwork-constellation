# Issue #13 — deterministic settled island layout

Implemented in `fix/issue-13` against the Constellation MVP. This report is scoped to observed evidence; it does not close the GitHub issue.

| Acceptance criterion | Evidence |
| --- | --- |
| Identical snapshot/revision/seed gives identical coordinates | Pure `layoutGraph` supports an explicit seed and canonical group/node ordering. Worker task tests reverse inputs and check equality. Structural keys include physical membership, paths, labels, colors and seed; they exclude source overlays. |
| Source toggles do not recompute positions or reset camera | `useSettledLayout` starts work only when structural facts change. The browser test records actual layout-worker construction count and camera attributes before/after removing PR #256; both stay unchanged. Source-only files newly entering inventory necessarily extend layout; surviving coordinates are preserved. |
| Worker, cancellation and a settled result | The web bundle contains a dedicated module worker. Each request has one worker, no queued work, abort termination, a 15-second timeout, detached callbacks and stale-reply rejection. Unit tests prove cancellation, pre-cancellation, faults and timeout. The renderer consumes a final result and never runs a physics loop. |
| Incremental refresh with explicit added/deleted files | Worker tasks preserve the coordinates of surviving IDs in unchanged groups, remove absent IDs, and place added files. Newly created islands are placed outside surviving hulls. Explicit finite world-space file pins are supported by the layout API and included in hull/bounds computation. |
| Legible island files and edge cases | Existing label reserve is retained. Tests cover a 2,000-file giant island, a one-file island, an empty island and disconnected files, without dropping files or overlapping the giant hull with neighboring hulls. Source edges do not affect placement, so high-degree nodes cannot pull other islands around. |
| Manual grouping preview/reset; camera/current file retained | Current map coordinates are retained for unchanged membership. Eight settled revision layouts are cached, so undo to a recent structural revision restores its exact coordinates. Camera framing happens only when the repository changes; surviving selected/focused coordinates do not trigger recentering on a source update. A visible **Reset island layout** action recomputes deterministic positions without clearing selection or grouping. `previewLayoutChanges` exposes before/after world coordinates for review UI. **Remaining:** the grouping review UI still displays moved-file counts rather than rendering a proposed movement preview; the UX-04 integration must consume that helper before claiming this whole criterion complete. Pins are an API capability, not a new drag-to-pin UI. |
| Giant group remains navigable | Dominant groups receive sufficient world space and separated placement. All file circles remain present; normal camera, island focus, minimap and file list work on the result. |

The 10k run recorded 51–68 ms long tasks during panning. These are contended-host observations, not evidence that release performance budgets pass; GRAPH-04 owns the final renderer performance gate. No browser/GPU capacity certification or manual assistive-technology review is claimed.

The worker, cancellation, stable refresh, seed, reset and regression work is ready to integrate. Do not replace the issue's original acceptance criteria with this report.
