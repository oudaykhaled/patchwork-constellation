# Issue #15 — continuous graph navigation

Implemented on 2026-11-03 against the 212-file Constellation fixture. This change owns camera/input, minimap, fit and semantic detail. It does not replace the layout worker from #13.

## Changes and acceptance evidence

| Criterion | Implementation and evidence |
| --- | --- |
| Drag / anchored wheel / pinch / explicit fit | Pointer capture pans continuously. Wheel uses the pointer anchor. Two-touch pinch now preserves the old world midpoint under the translated new midpoint, fixing translation loss and the dropped first pinch movement. Toolbar has +, −, Fit all, Fit selected island; labels also focus their island. Chromium real CDP multitouch and pure anchor tests pass. |
| Alternatives / browser navigation | Arrow buttons, canvas arrow keys, +/−, 0/Home, Escape and minimap arrow/Home work. Modified keyboard/wheel events pass through without preventDefault, retaining browser zoom/navigation. WebKit and Chromium keyboard/minimap tests pass. |
| Bounded zoom / inset-aware fit | Minimum wheel/button/pinch zoom is 0.32 × current Fit scale. Maximum is max(4.8 world-to-CSS-pixel scale, 8 × Fit scale). Fit uses a documented safe rectangle: top 125, bottom 110, horizontal24 CSS px on desktop; narrow controls reserve top 250/bottom 140. Desktop inspector width is measured and its right margin reserved. Fit and selected-file anchoring use these insets. Navigation moves left of the desktop inspector. Unit tests prove complete bounds remain in the safe rectangle; browser test proves it stays left of inspector. |
| Minimap viewport / exact mapping | SVG rectangle represents the full viewport. Click maps through the inner SVG client rectangle, excluding button padding/border; out-of-bounds points clamp to the repository rectangle. Click, arrows, Home and focus retention tested. |
| Semantic detail / collisions | Island labels remain overview controls; overlapping island labels are suppressed in priority order. Medium/close zoom prioritizes changed, selected, hovered, searched and neighboring filenames. Canvas filename collision checks now reserve island-label regions. Context import lines stay subtle and selected/hovered file connections are emphasized with direction arrows. |
| One circle / explicit reduction | Every positioned dot remains one file. Visible file count is always shown beside total file count; offscreen files remain in Files. Large overview shows the exact number of background import lines suppressed; selecting a file retains all its focused connections regardless of suppression. No aggregate node substitutes for file dots. |
| Search / selection / hover | Search and selected/hovered labels have priority. Selection has four corner brackets, a non-color cue distinct from the circular multi-source ring. Selected file focus fits away from the inspector. |
| Motion / interruption | Reduced motion skips camera animation. Pointer, wheel, toolbar pan, keyboard and minimap cancel the current requestAnimationFrame transition. An E2E test waits past the 320 ms transition and verifies camera stays stopped. Resize test verifies controls remain in the viewport. |

## Integration API

- `initialCamera?: Camera` restores a finite, positive saved camera on first/new-context framing. `onCameraChange?: (camera:Camera)=>void` reports actual updates, including animation frames; consumers should throttle URL persistence rather than rerender on every frame.
- `overviewRequest?: number` triggers Fit all when changed after initial mount, for the inspector's Back to overview action.
- When merging #13, use its worker-ready layout framing, then choose validated saved camera or `fitBounds(layout.bounds)`. Do not restore a saved camera before settled geometry arrives or re-fit on source-only array updates.

## Remaining validation gates

The original issue explicitly requires pointer, touch, keyboard, resize, inspector-open and browser-zoom scenarios. Its remaining unrecorded scenario is **actual native browser zoom**. Modified-event passthrough and narrow/resize automated journeys prove their own scope and must not be relabeled as native zoom. Record the browser's displayed 200% setting, actual reflow, reachable navigation, source selection and inspector behavior before closing this issue. A broader physical touch/trackpad matrix and human visual review across arbitrary repositories remain useful follow-ups; they are not additional acceptance requirements stated in this issue.
