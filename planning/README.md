# Planning manifest

issues.json contains 31 reconciled implementation tasks with stable keys, titles, areas, priorities, sizes, milestones, dependencies and acceptance/verification bodies.

The graph is acyclic, every dependency exists and no issue depends on a later milestone. Keys identify handoffs across GitHub numbering. GitHub issues/Project are the live execution record; this manifest is the original reviewed plan.

Sizes are relative complexity, not days. P0 establishes/protects the core path; P1 completes intelligence/beta capability. No implementation completion is asserted.
